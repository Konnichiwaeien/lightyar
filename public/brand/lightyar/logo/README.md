# Комплект логотипа «Светлый»

Обновлённая система сохраняет исходную идею — собака, лошадь и кошка внутри круглой эмблемы — и переводит её в самостоятельный вектор.

## Что использовать

- `svg/lightyar-primary-color.svg` — основной логотип для сайта, соцсетей, афиш и большинства печатных материалов.
- `svg/lightyar-horizontal-color.svg` — шапки сайта, подписи партнёров, широкие баннеры.
- `svg/lightyar-symbol-color.svg` — аватары, наклейки и ситуации, где название уже находится рядом.
- `svg/lightyar-micro-color.svg` — favicon и размеры от 16 до 32 px.
- `svg/lightyar-official-color.svg` — документы и официальные материалы с «АНБО».
- Файлы `*-mono.svg` — одноцветная печать, штамп и гравировка.
- Файлы `*-inverse.svg` — размещение на тёмном фоне.

SVG — основной исходный формат. Он масштабируется без потери качества, не содержит растровых вставок и не зависит от установленных шрифтов.

## Палитра

- Янтарь: `#E9A91B`
- Мягкий чёрный: `#1C1C1B`
- Тёплая бумага: `#F7F3EB`

## Минимальные размеры

- Основная эмблема: 160 px по ширине.
- Горизонтальная версия: 220 px.
- Знак без надписи: 64 px.
- Микрознак: 16 px.
- Официальная версия: 280 px.

Для маленьких размеров не уменьшайте основную эмблему ниже 160 px — используйте `symbol` или `micro`.

## Охранное поле

Оставляйте вокруг логотипа свободное пространство не меньше половины высоты буквы «С» в слове «Светлый». Не прижимайте знак к краю фотографии, рамке или соседнему логотипу.

## Нельзя

- менять пропорции;
- перекрашивать отдельные линии случайными цветами;
- добавлять тени, обводки и градиенты;
- ставить цветную версию на пёстрый участок фотографии без спокойной подложки;
- использовать детальную эмблему вместо микрознака в favicon.

PNG находятся в папке `png/` и предназначены для сервисов, которые не принимают SVG. PDF-гайд лежит рядом с этим README.
