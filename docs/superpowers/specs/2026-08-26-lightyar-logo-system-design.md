# Система логотипа «Светлый»

## Цель

Обновить старую круглую эмблему без потери узнаваемости и выпустить самостоятельный векторный комплект для сайта, социальных сетей, документов, печати и мерча.

## Утверждённое направление

- Степень изменения: умеренная перерисовка.
- Характер: «Живая линия» — тёплый авторский контур с осмысленным изменением толщины штриха.
- Сюжет: собака слева, лошадь справа, кошка снизу; круглая композиция сохраняется.
- Основная надпись: «Светлый».
- Официальная подпись: «АНБО „Светлый“» только в отдельной версии.
- Палитра: янтарь `#E9A91B`, мягкий чёрный `#1C1C1B`, тёплая бумага `#F7F3EB`.

## Принцип рисунка

Животные не копируются пиксельно. Их силуэты очищаются, лица получают единый ритм и одинаковую степень детализации. Контур остаётся живым, но в нём не должно быть случайных пересечений, слишком тонких усов или деталей, исчезающих при уменьшении.

## Адаптивная система

1. `primary` — круглая эмблема с животными и названием.
2. `horizontal` — знак слева, название справа.
3. `symbol` — круглый знак без надписи.
4. `micro` — сильно упрощённый знак для 16–32 px.
5. `official` — горизонтальная версия с подписью «АНБО „Светлый“».

Каждая основная компоновка выпускается в цветном, монохромном и инверсном вариантах. SVG не содержит растровых вложений, масок с внешними ресурсами или обязательных внешних шрифтов.

## Комплект

- Редактируемые SVG.
- PNG с прозрачным фоном для типовых цифровых размеров.
- PDF-лист с системой, палитрой и правилами применения.
- README с назначением файлов, охранным полем и минимальными размерами.

## Критерии приёмки

- Основная эмблема остаётся узнаваемой рядом со старым логотипом.
- Все три животных читаются при ширине 96 px.
- Микроверсия читается при 16 и 32 px.
- Монохром не теряет ключевые формы.
- SVG масштабируется без пикселизации и открывается без внешних ресурсов.
- PNG имеют настоящий прозрачный фон там, где он заявлен.
