# Промпт для Codex: тематические росчерки для страницы отчётности

Скопируйте всё, что ниже разделителя, в Codex одним сообщением. Промпт
самодостаточный: там и что рисовать, и куда класть, и как проверить.

Почему белым на прозрачном, а не янтарным: файл подключается как CSS-маска,
цвет задаётся стилями. Один файл работает в любом цвете и сам подхватит смену
фирменного янтаря, если мы его поменяем.

---

Ты работаешь в проекте `C:\Development\Crafting\lightyar\lightyar` (Next.js, сайт
приюта «Светлый»). Нужно сгенерировать пять растровых росчерков для страницы
годовой отчётности, проверить их и разложить по местам.

## Что рисуем

Общий стиль для всех пяти: рисунок от руки, живая неровная линия, следы кисти
или карандаша. Не векторная гладкость, не иконка из библиотеки, не клипарт.
Один элемент на файл, без рамок, без подписей, без фона.

## Требования к файлам

Одинаковые для всех пяти, нарушение любого пункта означает переделку:

1. Формат PNG с альфа-каналом.
2. Рисунок **чисто белый** (`#FFFFFF`), фон **полностью прозрачный** (альфа 0).
   Никакого цвета, никакого серого фона, никакой тени и обводки.
3. Рисунок занимает почти всё поле кадра: пустые поля по краям не больше 3%
   от стороны.
4. Один элемент на файл. Никаких дублей, вариантов рядом, сеток и подписей.
5. Точные размеры из таблицы, пиксель в пиксель.

## Куда положить

Каталог `public/reports/marks/` (создай, если его нет). Имена файлов ровно
такие, как в таблице.

## Как проверить

Проверку выполни сам, глазами и скриптом, до того как отчитаешься.

Скриптом, из корня проекта. Скрипт должен вывести по каждому файлу размер,
наличие альфы, долю прозрачных пикселей и убедиться, что цветных пикселей нет:

```bash
node -e "const sharp=require('sharp');const fs=require('fs');(async()=>{for(const f of fs.readdirSync('public/reports/marks')){const p='public/reports/marks/'+f;const{data,info}=await sharp(p).ensureAlpha().raw().toBuffer({resolveWithObject:true});let clear=0,colored=0,ink=0;for(let i=0;i<info.width*info.height;i++){const r=data[i*4],g=data[i*4+1],b=data[i*4+2],a=data[i*4+3];if(a<10){clear++;continue}ink++;if(Math.max(r,g,b)-Math.min(r,g,b)>12||Math.max(r,g,b)<200)colored++}console.log(f,info.width+'x'+info.height,'прозрачных',Math.round(clear/(info.width*info.height)*100)+'%','цветных',colored,colored>ink*0.02?'ПЛОХО: рисунок должен быть белым':'ok')}})()"
```

Глазами: положи каждый файл на янтарный фон `#f59e0b` и на бумажный `#e8e4dc`,
посмотри в масштабе 100% и уменьшенным до реального размера на странице
(росчерк под цифрой занимает примерно 120 px по ширине). Если в уменьшении
рисунок превращается в кашу, упрости: меньше деталей, толще линия.

Готовые файлы покажи пользователю одним контактным листом на янтарном фоне.

инициативе, сначала спроси.
