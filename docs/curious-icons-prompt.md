## Стилистика: родня уже нарисованных

Открой `public/reports/marks/hourglass.png`, `stethoscope.png` и
`dog-medium.png`: новые файлы должны стоять с ними в одном ряду. **Белый
силуэт с фактурой сухой кисти на полностью прозрачном фоне.** Линия живая и
неровная, местами краска легла плотно, местами просвечивает.

Важно про плотность: `calendar.png` из прошлой партии не подошёл, потому что
вышел сплошным пятном, при уменьшении до 56 px он читался как квадрат.
Все новые иконки рисуй **контуром с просветами**, а не заливкой: доля
прозрачного внутри силуэта должна быть заметной.

Чего быть не должно: цвета, акварели, книжной иллюстрации, зверей-персонажей,
трёхмерного рендера, глянца, теней, рамок, подложек, текста и цифр. Файлы
подключаются масками, поэтому любой цветной пиксель сломает подключение.

Общее для всех: один предмет по центру, поле вокруг не больше трёх процентов
стороны, никаких дублей и вариантов на одном листе. Иконки мелкие, около
56 px на странице: формы крупные, линия толстая, деталей минимум.

## Куда положить

В `public/reports/marks/`, именами из таблицы. Старый `calendar.png` не трогай.

## Как проверить

Прогони до отчёта, из корня проекта. Скрипт печатает размер, долю
прозрачного фона, долю просветов внутри силуэта и ругается на цвет:

```bash
node -e "const sharp=require('sharp');const fs=require('fs');(async()=>{for(const f of ['clock.png','glasses.png','scales.png','camera.png','snowflake.png','dog-head.png','cat.png','calendar-grid.png']){const p='public/reports/marks/'+f;if(!fs.existsSync(p)){console.log(f,'НЕТ ФАЙЛА');continue}const{data,info}=await sharp(p).ensureAlpha().raw().toBuffer({resolveWithObject:true});let clear=0,colored=0,ink=0;for(let i=0;i<info.width*info.height;i++){const r=data[i*4],g=data[i*4+1],b=data[i*4+2],a=data[i*4+3];if(a<10){clear++;continue}ink++;if(Math.max(r,g,b)-Math.min(r,g,b)>12||Math.max(r,g,b)<200)colored++}const fill=Math.round(ink/(info.width*info.height)*100);console.log(f,info.width+'x'+info.height,'краски',fill+'%',fill>55?'СЛИШКОМ ПЛОТНО: нужен контур':'ok','цветных',Math.round(colored/Math.max(ink,1)*100)+'%',colored>ink*0.02?'ПЛОХО: рисунок должен быть белым':'ok')}})()"
```

Глазами: положи каждый файл на янтарный `#f59e0b` и бумажный `#e8e4dc` фон
в размере 56 px. Если предмет превращается в пятно, упрости или добавь
просветов.

Готовые файлы покажи одним контактным листом на янтарном фоне рядом с
`hourglass.png` для сравнения.
